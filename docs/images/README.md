# Bilder für das Handbuch

Hier liegen die Screenshots und Grafiken, auf die `../Handbuch.md` per
`![Beschreibung](images/dateiname.png)` verweist.

- Dateiformat: PNG
- Dateiname: exakt wie im jeweiligen Platzhalter in `Handbuch.md` angegeben
- Empfohlene Breite: ca. 900–1200 px (reicht für gute Lesbarkeit im PDF,
  ohne die Datei unnötig groß zu machen)

Sobald eine Datei hier abgelegt ist, wird sie beim nächsten PDF-Export
automatisch eingebunden — an `Handbuch.md` muss dafür nichts geändert
werden. Details siehe Anhang B in `Handbuch.md`.
